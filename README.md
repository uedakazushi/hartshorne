標数0の P^n（n≥7）上の階数2ベクトル束の分解予想を最上位目標とする。完全交叉、P5/P6、有限延長、cohomology・syzygy・数値条件、関連する独立した問題を並行して扱う。

## 現在の成果と限界

**Hartshorne 予想自体は未解決。新しい次元範囲の分解定理は得ていない。** 現在は有限厚化の余核を測る Jordan 公式に加え、モナドの法線係数による正確な分裂次数と、全ての捩りのコホモロジーで検出できない非零の延長を原稿にした。証明と新規性は別に扱い、主原稿は新規性確認前の研究草稿である。

- **欠損公式：** H_k=(h^{k+1}=0) から H=(h=0) への H^{i−1} の制限余核は、H^i_*(F) の h-Jordan block のうち長さ≤kのものを、終端の次数付きで数える。有限次数の分解判定と regularity による上界が従う。
- **実際の分裂次数：** 両端が階数1の交代形式付きモナドについて、法線展開の最初の非零係数の次数νが最初の非分裂次数に一致する。負の捩りのモナド変形から Ext1 への単射を証明した。一般定理は標数≠2で成立する。
- **鋭い例：** P3 上の null-correlation 束の座標 d乗写像による引き戻しは rank2、c1=0、c2=d²。座標超平面では還元が d−1次まで分裂し、d次で初めて非分裂になる。最初の H0 欠損の総次元は d³。
- **超平面依存：** 同じ束の一般超平面では一次ですでに欠損 d が twist d−1 に現れる。一次式の台の大きさごとに最初のコホモロジー欠損を計算した。標数0では、座標超平面と対応する座標中心の組を除き、実際の還元はすべて一次で非分裂である。
- **コホモロジーの検出限界：** 偶数d≥2・台が3の超平面では、全ての捩り・全てのコホモロジー制限が全射でも、どの線形射影についても還元は非分裂。制限束EはP2上で安定で、Ext1(E,E(−1))内に全てのコホモロジー写像が零となる4次元部分空間を明示した。
- **不可視な延長の全空間：** P2上の任意の安定rank2束Eでc1=0、c2=4、H1(E(1))=0なら、全不可視延長空間は正確に12次元。Ext1(E,E(−1))（16次元）から Hom(H0(E(1)),H1(E))（4次元）への全射の核として記述した。モナド表示を仮定しない一般証明で、上のd=2例にも適用できる。
- **奇標数：** d=p^a u、p∤u の座標冪では、上記の特殊な座標対以外の最初の非分裂次数はp^a。純Frobenius冪では全ての対でd次となる。標数0の安定性やJordan表を小標数へ無条件には移さない。
- **算術の再現基盤：** Schwarzenberger 条件の素数別の最初の失敗次数、P5/P6/P7 の全数値解、有限次元での無限の数値的候補を厳密に記述した。中央階乗積・奇素数分類は既知文献と比較し、実在する束の構成とは区別する。
- **本質的な障害：** 任意の束は線形射影によってすべての形式近傍へ延長する。問題は大域的な局所自由延長や、その実際の厚化構造にある。数値・位相条件だけで負の判別式を一括排除する方針にも既知の限界がある。
